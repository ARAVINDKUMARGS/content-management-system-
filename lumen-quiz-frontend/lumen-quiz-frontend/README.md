# Lumen Quiz Frontend

React + Vite frontend matching the supplied Lumen "New Article / Add a Quiz" screens.

## Run

```bash
npm install
npm run dev
```

## Included

- Lumen-style top navigation
- New Article form
- Category and tags
- Article content editor
- Add Quiz toggle
- Dynamic questions
- Four options per question
- Correct-answer selection
- Add/remove questions
- Save Draft using localStorage
- Submit-for-review validation
- Responsive layout

The `payload` object in `src/main.jsx` is the integration point for the backend API.
